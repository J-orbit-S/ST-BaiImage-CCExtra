# 划线出图 · 柏宝绘伴生插件（ST-BaiImage-CCExtra）

**一句话：在正文里划一段，就地出这张图。**

不用整层楼重跑，不用把那句话单独复制出来重新组织，划到哪里就出哪里。

---

## 它解决什么问题

柏宝绘是按「一整层楼」出图的：把这一楼的全部正文送给模型，让它判断该画几张、画什么。

但实际读剧情的时候，你常常只想要其中一句——那句对视、那个回头、那句「他低头吻她的手背」。为了这一句去跑一整层楼，既浪费额度，也浪费时间；更麻烦的是，模型可能顺手给这一楼画出三张你并不想要的图。

这个插件做的事很小：**把「送给模型的一整层楼」换成你划的那几行。**

其余全部照旧——同一套提示词、同一套规范、同一个副 API、同一种写回格式，代码是从柏宝绘逐字搬过来的。"划线"只是换了入口，分析过程和柏宝绘完全一致。

---

## 三种用法，看你现在想不想要图

划完正文，选区上会浮出按钮：

### ⚡ 生成 —— 现在就要

按你在面板里的设置，走三条路之一：

- **全自动**（默认）：等一两秒，正文里多出图片标记，卡片自己开始画。
- **需确认**：先只生成候选 tag，面板弹出，你确认了才写进正文。不满意可以重 Roll、手改、删掉，都不碰正文。
- **全手动**：只把 tag 写进去，出图你自己点卡片。

### ＋ 待生成 —— 先攒着

点了只记下这段文字，**不调 API、不打断阅读**。

看到后面又碰上喜欢的段落，继续攒。攒够了打开面板，点一次「一键生成全部」：

- **同一楼的多段只调一次副 API**，每段各出一张 tag，互不影响；
- 省下来的是系统提示词那几万 token——原本每段都要重复发一遍；
- 模型漏掉的段会自动逐条补发，已经生成好的不会重来。

适合「一口气读完一楼，再回来挑画面」的读法。

### ✕ 取消

分析途中按钮会变成红色的「取消分析」，点它（或按 Esc）立刻中止，正文一个字都不会改。

## 中文对照

英文 tag 看着累，这是实话。

开了中文对照之后，副 API 在**同一次调用**里顺手多给一份中文直译：Base tag 翻，角色分项（「角色: 叶均」下面那串）也逐条翻。就显示在候选卡片上，**只给你看，绝不写进正文**，也不进提示词。

手改过英文之后，对应的中文会自动消失——它不知道你改成了什么，宁可不给，也不给一个错的对照。

## 手机上也能用

长按划线，松手后按钮自动浮出，触屏下按钮会放大到好点的尺寸。

按钮压在**选区内部偏下**的位置：那一条「选区下方」是系统拷贝菜单和其他划线插件的公共地盘，不去抢。

---

## 和柏宝绘是什么关系

一句话：**它是柏宝绘的伴生工具，不是替代品，也不改柏宝绘一行代码。**

- 只读柏宝绘的设置与角色库，一个字节都不写；
- 提示词、规范、方案、副 API 全在柏宝绘里改，插件每次请求现读——**改完下一次划线立刻生效**，不用重启；
- 真正出图还是柏宝绘的卡片，画师串、负面词、并发限制、图库、历史全部走它原来的逻辑；
- 自己的设置只有四个开关：**自动出图、需确认、中文对照、显示悬浮球**；
- 面板直接借用柏宝绘的界面和主题——你在它里面切夜间 / 粉彩，这个面板同时跟着变。

入口有三个：划线浮出的按钮、屏幕边缘可拖动的悬浮球、输入框上方魔术棒菜单里的「划线出图」。

## 安装

1. 先装好并配置[柏宝绘](https://github.com/baibai-git/ST-BaiBai-Image)（0.3.6 为锚点版本）。
2. 把本仓库整个目录放进扩展目录，二选一：
   - `SillyTavern/public/scripts/extensions/third-party/ST-BaiImage-CCExtra/`
   - `SillyTavern/data/<你的用户名>/extensions/third-party/ST-BaiImage-CCExtra/`
3. 刷新 SillyTavern。控制台出现 `[CCX] ST-BaiImage-CCExtra x.x.x 已加载` 就装好了。

仓库里已经带了构建好的 `dist/index.js`，**不需要自己编译**。

## 几个需要先知道的边界

- **不能跨楼划线**，跨楼请分两次划。
- **同一段连续划两次会被拦一次**，提示「已经出过图了」；想重出，先在卡片里把那张删掉。
- **重 Roll 只换提示词，不重新出图**——花的是文本额度，不是图片额度，心疼画图额度时可以放心重 Roll。
- **划完之后如果别的插件改了正文**，会提示「请重新划线」（原文对不上了），保护你不会把图插错位置。
- **自动出图依赖柏宝绘卡片的结构**：柏宝绘大改版后，可能出现「tag 写进去了、图没自动出来」，点一下卡片就好，不会写坏任何东西。
- **漫画页（多段合成一页）还没做**：设计已定，代码未动。目前是「一段一张单图」。
